# Worldgen V1

Référence de conception dans la [Bible Minecraft](https://app.notion.com/p/41b9f448fe03810485f6ebd0d3cb8fae), sections Monde, Relief, Hydrologie, Précipitations et Échelle climatique.

- 240 000 blocs de côté, génération à la demande, terrain et climat déterministes selon la graine.
- Continents de taille variable, tectonique simplifiée et détails locaux continus.
- Hémisphère unique, sud chaud / nord froid, pluies géographiques et drainage par bassins.
- Preset Minecraft Java 26.3 pour Fabric et Java 25, avec biomes et ressources vanilla.
- Les paramètres techniques sont spécifiques à cette V1. Voir [architecture](../../docs/architecture.md).
